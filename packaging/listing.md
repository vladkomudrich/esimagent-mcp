# eSIM Agent

**Subtitle:** Compare eSIM plans instantly

## Description

Find the perfect eSIM plan for your next trip. Compare prices from 50+ providers, filter by data and duration, and buy the cheapest option — all in three clicks.

No more overpriced airport SIM cards or roaming charges. Search any country, see plans side by side, and get connected before you even board the plane.

## Key Features

- Compare plans from 50+ eSIM providers in one place
- Filter by data amount, duration, and price
- Curated deals and promo codes updated regularly
- Device compatibility checker with step-by-step installation guides
- MCP server for AI assistants — search plans through Claude, Cursor, GPT, and more
- Works as a PWA — add to your home screen for native app experience
